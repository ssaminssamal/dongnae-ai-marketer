# 동네AI 마케터

실제 상품 사진 1~3장과 사장님이 입력한 사실을 바탕으로 AI 문구와 광고 영상을 제작합니다.

## 실행

Python 3.11을 권장합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows에서는 `run_vscode.bat` 또는 `python launch_app.py`도 사용할 수 있습니다. 기본 앱 주소는 http://localhost:8503 입니다. `launch_app.py`는 기존 모바일 접속 화면을 제공하는 선택 실행기입니다.

`.env.example`을 `.env`로 복사하고 `GEMINI_API_KEY`(문구), `RUNWAYML_API_SECRET`(영상)을 설정하세요. 기본 문구 모델은 `gemini-3.5-flash-lite`이며 `GEMINI_COPY_MODEL`로 바꿀 수 있습니다. 키는 화면·다운로드·Git에 포함하지 마세요. API 호출에는 각 서비스 비용이 발생합니다.

## 제작 흐름

1. 업종·가게명·상품·특징과 확인된 가격/할인/효능 문장을 입력합니다.
2. 실제 사진 1~3장을 업로드합니다. 순서대로 장면을 만듭니다.
3. 실제 AI 호출로 문구를 생성하고 편집합니다. 가격·할인·효능·수치 등 민감한 주장이 입력 문장과 일치하지 않으면 제작과 TTS 미리 듣기를 차단합니다. 입력 변경 시 문구를 다시 생성해야 합니다.
4. 상품 보존 연출이 기본 적용됩니다. 필요한 경우 접힌 장면 연출 설정에서 프롬프트를 편집합니다.
5. Runway로 장면을 생성한 뒤 한글 자막·TTS를 합쳐 MP4로 내려받습니다. 같은 사진·모델·연출의 장면은 세션에서 재사용합니다. 음성 생성은 영상 생성 전에 수행합니다.
6. 오른쪽 미리보기에서 완성 영상을 확인하고 MP4로 내려받습니다.

검증은 보수적인 규칙 검사입니다. 민감한 주장의 의역도 차단될 수 있고, 모든 자연어 허위를 탐지하지는 못하므로 사장님 검토가 필요합니다. 차단된 원문은 검증 기록에만 남고 영상 제작에는 사용되지 않습니다.

## 음성과 폰트

기본 음성은 온라인 gTTS로, 문구가 Google 음성 서비스로 전송됩니다. 로컬 음성은 선택 사항입니다.

```bash
python -m pip install -r requirements-local-tts.txt
python setup_free_tts.py
```

로컬 모델이 설치되면 Supertonic을 사용합니다. `DONGNAE_TTS_BACKEND=gtts` 또는 `local`로 지정할 수 있습니다. Supertonic 모델의 라이선스·NOTICE를 유지하세요. Windows는 맑은 고딕, Linux는 Nanum/Noto CJK를 탐색합니다. `DONGNAE_FONT_PATH`로 폰트를 지정할 수도 있습니다.

## 평가와 한계

실제 가게 3곳 이상에서 사진 조건 5개 이상을 정하고 같은 사진을 개선 전/후 각각 제작하세요. 최종 제작 화면은 보존 프롬프트와 최소 카메라 이동을 기본 적용합니다. 실험 조건 선택과 평가표는 일반 제작 화면에서 표시하지 않습니다. 연구 기록이 필요할 때만 `DONGNAE_REVIEW_MODE=1`로 평가 도구를 켤 수 있습니다. 기존 비교용 프롬프트 생성 함수는 코드에 보존되어 있습니다. 원본 상품 영역 합성은 구현하지 않았습니다. 왜곡률 개선은 보장하지 않으며 실제 영상을 보고 평가합니다.

글자가 없는 사진의 글자 항목은 `해당 없음`으로 표시합니다. 왜곡률은 `왜곡 / (정상 + 왜곡)`이며 미평가 수를 따로 표시합니다. 동일 사진 묶음의 전후 결과를 비교하고, 실제 사장님 2명 이상의 사용 가능 여부와 수정 의견을 기록하세요. 문구 생성 원문·차단 결과와 최종 수정 문구·검증 결과가 기록됩니다. 실험 수치나 사장님 답변은 자동으로 만들지 않습니다.

평가 데이터는 브라우저 세션에 보관되므로 종료 전에 JSON을 내려받으세요. 생성 영상은 `outputs/`에도 저장됩니다. Cloud의 로컬 파일은 영구 보관되지 않습니다. 기존 개인 데이터 파일은 삭제하지 않지만 앱은 지역 데이터나 위치 파일을 읽지 않습니다.
